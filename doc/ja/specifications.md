# 確定申告ソフトウェア 仕様書（現行機能詳細）

本書は、Rust / Dioxus で実装された確定申告デスクトップアプリケーション（`TaxReturnApplication-Dioxus`）の**現行バージョン（v0.1.0）における実装済み機能、動作仕様、データ入出力、および操作方法**を網羅的にまとめた仕様書です。

---

## 1. アプリケーション概要

### 1.1 基本コンセプト
- **Pure Rust スタック**: Dioxus（Desktop）を用いた単一バイナリ配布可能なデスクトップアプリケーション。UI層に JavaScript / TypeScript を一切使用せず、Rust RSX のみで構築。
- **データプライバシー・完全ローカル性**: クラウドへの送信を行わず、ユーザー端末のローカルストレージ（JSON）のみで完結。
- **モダンな操作性**: 複雑なExcelグリッドの模倣を避け、**「モダン入力フォーム ＋ 検索・ソート・絞り込み可能な仕訳一覧テーブル」**で高速かつ軽快な帳簿付けを実現。
- **レガシー資産の継承**: 旧来のExcelマクロベースの税務ツールが出力するCSVデータ（Shift_JIS / 2行ヘッダー）の高速インポートパイプラインを標準搭載。
- **税務帳票PDFの自動生成**: 入力された仕訳から、青色申告決算書（損益）および確定申告書Bの概算数値を自動算出し、PDFとして出力。

## 3. 仕訳帳・帳簿管理機能（LedgerPage）

### 3.1 会計年度の選択・切り替え
- **対象年度**: 現在年度を中心とする前後複数年度（`選択年度 - 3年` 〜 `選択年度 + 1年`）をドロップダウンで即座に切り替え可能。
- **年度切り替え時の動作**:
  - 切り替えた年度のデータファイル（`{fiscal_year}.json`）をストレージから自動読み込み。
  - 編集中ステートおよびCSV解析プレビューは自動リセット。

### 3.2 仕訳データモデル（`JournalEntry`）
1件の仕訳は「単一の借方・単一の貸方」を持つ複式簿記形式で構成されます。

| 項目名 | 型 / 形式 | 必須 | 説明・バリデーション規則 |
|---|---|:---:|---|
| **ID** | `String` (UUID v4) | 必須 | 仕訳ごとに一意な識別子。自動生成。 |
| **日付 (`date`)** | `NaiveDate` (YYYY-MM-DD) | 必須 | 取引日。**選択中の会計年度内（1月1日〜12月31日）であること**が必須。 |
| **借方科目 (`debit`)** | `AccountCode` | 必須 | 借方勘定科目（標準科目およびカスタム科目）。 |
| **借方補助科目 (`debit_sub`)** | `Option<String>` | 任意 | 銀行口座名や取引先名などの補助科目。 |
| **貸方科目 (`credit`)** | `AccountCode` | 必須 | 貸方勘定科目。**借方と同一科目は指定不可（ただし借方・貸方の補助科目が異なる資金振替仕訳を除く）**。 |
| **貸方補助科目 (`credit_sub`)** | `Option<String>` | 任意 | 銀行口座名や取引先名などの補助科目。 |
| **金額 (`amount`)** | `i64` (円単位) | 必須 | 取引金額。浮動小数点誤差を排除するため整数（円単位）で保持。**1円以上（正の整数）**が必須。 |
| **摘要 (`description`)** | `String` | 必須 | 取引先や内容のメモ。**空白のみの入力は不可**。 |
| **作成日時 (`created_at`)** | `DateTime<Local>` | 必須 | 作成時刻タイムスタンプ。同日内ソートの安定化に使用。 |

### 3.3 仕訳の入力・編集・削除
1. **新規登録**:
   - フォーム（日付、借方、貸方、金額、摘要）に入力し「登録」ボタンをクリック。
   - バリデーションエラー時はフォーム直下に日本語エラーメッセージをインライン表示。
   - 登録完了後、金額・摘要欄はクリアされ、日付欄は次に入力しやすいよう保持。
   - ストレージへの**自動保存**が即座に実行される。
2. **編集**:
   - 一覧テーブルの各行にある「編集」ボタンをクリックすると、フォームが編集モードに切り替わり該当データが反映される。
   - フォームヘッダーが「仕訳の編集（ID: ...）」に変化し、「キャンセル」ボタンが出現。
   - 「更新」をクリックすると該当IDのデータが書き換えられ、自動保存される。
3. **削除**:
   - 一覧テーブルの各行にある「削除」ボタンをクリックすると即座に一覧から除外され、自動保存される。

### 3.4 リアルタイム・フィルタリング＆ソート
一覧テーブル上部のコントロールにより、画面遷移なしで瞬時に絞り込みが可能です。

- **テキスト検索**: 摘要文、借方科目名、貸方科目名のいずれかに一致するレコードを部分一致検索。
- **科目絞り込み**: 全勘定科目ドロップダウンから選択。借方または貸方のいずれかに該当科目を含むレコードを抽出。
- **期間指定（日付範囲）**: 開始日・終了日による範囲指定。
- **ソート切り替え**:
  - 「日付（新しい順）」: 取引日付の降順 → 作成日時の降順
  - 「日付（古い順）」: 取引日付の昇順 → 作成日時の昇順
- **統計表示**: 絞り込まれた現在のレコード件数、および**絞り込み後の合計金額（¥表示）**をリアルタイムで自動計算・表示。

## 4. 勘定科目仕様（Chart of Accounts）

| 勘定科目（日本語表記） | 内部識別子 (`AccountCode`) | 勘定分類 (`AccountNature`) | 決算書・残高試算表での役割 |
|---|---|---|---|
| **現金** | `cash` | 資産 (Asset) | 手許現金 |
| **普通預金** | `bank` | 資産 (Asset) | 銀行口座残高 |
| **売掛金** | `accounts_receivable` | 資産 (Asset) | 未回収の売上代金 |
| **買掛金** | `accounts_payable` | 負債 (Liability) | 未払いの仕入代金 |
| **元入金** | `capital` | 純資産 (Equity) | 期首純資産（事業開始時元入金） |
| **事業主貸** | `drawings` | 資産 (Asset) / 純資産控除 | 事業用口座から個人用途への支出 |
| **事業主借** | `owner_contribution` | 負債 (Liability) / 純資産加算 | 個人資金から事業用への投入 |
| **売上高** | `sales` | 収益 (Income) | 本業の売上収入金額 |
| **仕入高** | `cost_of_sales` | 費用 (Expense) | 売上原価（仕入） |
| **旅費交通費** | `travel` | 費用 (Expense) | 電車・バス代、出張旅費 |
| **通信費** | `communication` | 費用 (Expense) | 電話代、切手、インターネットプロバイダ費用 |
| **消耗品費** | `supplies` | 費用 (Expense) | 10万円未満の備品・PC周辺機器・文房具 |
| **地代家賃** | `rent` | 費用 (Expense) | 事務所・事業用賃料 |
| **水道光熱費** | `utilities` | 費用 (Expense) | 電気代、水道代、ガス代 |
| **広告宣伝費** | `advertising` | 費用 (Expense) | 広告掲載料、チラシ印刷、Webプロモーション |
| **接待交際費** | `entertainment` | 費用 (Expense) | 取引先との飲食、慶弔見舞金、贈答品 |
| **損害保険料** | `insurance` | 費用 (Expense) | 店舗・事務所の火災保険、事業用賠償責任保険 |
| **修繕費** | `repair` | 費用 (Expense) | 建物やPC・設備の修理・維持管理費 |
| **福利厚生費** | `welfare` | 費用 (Expense) | 従業員・スタッフの健康診断、慰労費用 |
| **給料賃金** | `salaries` | 費用 (Expense) | 雇用スタッフへの給与支払い |
| **外注工賃** | `subcontracting` | 費用 (Expense) | 外部フリーランスや専門業者への委託費用 |
| **利子割引料** | `interest` | 費用 (Expense) | 事業資金借入金の利息 |
| **租税公課** | `taxes_and_dues` | 費用 (Expense) | 個人事業税、固定資産税、印紙税、自動車税（事業分） |
| **荷造運賃** | `packing_shipping` | 費用 (Expense) | 商品発送の送料、梱包ダンボール代 |

| **カスタム科目** | `Custom(String)` | 任意 (指定可) | ユーザーが自由に命名・分類して追加した独自勘定科目 |

## 5. 旧ExcelマクロCSVインポートエンジン

### 5.1 対象ファイル形式
旧来の確定申告用Excelマクロツールが出力する特殊な**「2行ヘッダー形式」**のCSVをサポートします。

```csv
日付,№,借　　　　方,,,貸　　　　方,,,,,集計科目コード１,集計科目コード２,集計除外摘要文１,集計除外摘要文２,摘　　要,摘要２,摘要３
日付,№,科目ｺｰﾄﾞ,勘定科目,金　　額,科目ｺｰﾄﾞ,勘定科目,金　　額,月,重複チェック,1,3,家事消費等,雑収入,摘要,摘要２,摘要３
1月5日,1,104,その他の預金,"165,000.00",1,売上（収入）,"165,000.00",1,FALSE,165000,0,0,0,賃料:(2026年1月分),,
```

### 5.2 エンコーディングの自動判別
- Windows / Excel 標準の **Shift_JIS (CP932)** および **UTF-8（BOM有無両対応）** を自動検出してデコード。文字化けを起こさずにインポート可能。

### 5.3 柔軟なパースロジック
- **日付パース**:
  - `YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD`
  - 日本語表記 `1月5日`, `01月05日`
  - スラッシュ省略表記 `1/5`, `01/05`
  - 全角数字（`１月５日` 等）の半角自動正規化
- **金額パース**:
  - `165,000.00` のようなカンマ・小数付き表記の丸め処理
  - `¥165,000`, `￥165,000` などの通貨記号や空白の自動除去
- **摘要の自動連結**:
  - 列14（摘要）、列15（摘要２）、列16（摘要３）に入力されたテキストを半角スペース区切りで1つの摘要に自動結合。
- **科目マッピングルール**:
  1. 日本語標準科目名との完全一致。
  2. 旧Excelコード判別（例: `1` → 売上高, `101` → 現金, `102`〜`105` → 普通預金, `111`〜`112` → 売掛金, `201`〜`215` → 買掛金, `301`〜`303` → 元入金/事業主貸/事業主借, `401`/`501` → 仕入高, `502`/`510` → 消耗品費, `503` → 水道光熱費, `504` → 旅費交通費, `505` → 通信費, `515` → 地代家賃, その他500番台 → 雑費）。
  3. 科目名キーワードヒューリスティック（例: "預金" "銀行" → 普通預金、"家賃" "地代" → 地代家賃、"電気" "ガス" → 水道光熱費 など）。
  4. 未定義科目のフォールバック: 貸方は「売上高」、借方は「雑費」に代替し、ユーザーへ警告メッセージを出力。

### 5.4 インポートUIと安全機能
- **ファイル選択ダイアログ (`rfd`)** または **テキストエリアへの直接貼り付け** に対応。
- **プレビュー画面**:
  - 取込可能件数、合計金額、対象行数、スキップ行数の要約表示。
  - 先頭5件の仕訳プレビュー表。
  - 科目マッピング警告（最大5件表示＋残件数）。
  - 不正行エラーメッセージ（最大5件表示＋残件数）。
- **取込モードの選択**:
  - 既存仕訳に追加（デフォルト）
  - 既存仕訳を全削除して置き換え（チェックボックスで選択）

## 6. 会計・税務計算エンジン（ReportPage）

すべての計算処理は純粋関数（Pure Function）として実装され、UI層から完全に独立して単体テストされています。

### 6.1 青色申告決算書（一般用）損益計算
1. **売上総利益**:
   $$\text{売上総利益} = \text{売上高} - \text{仕入高}$$
2. **経費合計**:
   旅費交通費 ＋ 通信費 ＋ 消耗品費 ＋ 地代家賃 ＋ 水道光熱費 ＋ 雑費
3. **青色申告特別控除前所得金額**:
   $$\text{特別控除前所得} = \text{売上総利益} - \text{経費合計}$$
4. **青色申告特別控除額の適用**:
   - 控除区分は「なし（0円）」「10万円控除」「65万円控除」から選択可能。
   - **所得上限キャップ**: 特別控除額は、控除前所得金額（黒字の場合）を上限とし、損失（赤字）をさらに拡大させる控除は行わない（所得が30万円で65万円控除を選択した場合、適用控除額は30万円）。
5. **事業所得金額**:
   $$\text{事業所得} = \max(\text{特別控除前所得} - \text{適用特別控除額}, 0)$$
6. **簡易貸借対照表残高**:
   現金、普通預金、売掛金、買掛金、元入金、事業主貸、事業主借 の各残高を集計。

### 6.2 確定申告書B 所得税概算計算
現行版では、事業所得と基礎控除を中心とした概算所得税額を計算します。

1. **所得金額合計**: 現在は事業所得金額を採用。
2. **基礎控除の算出（令和2年分以降の所得税法準拠）**:
   - 合計所得 2,400万円以下: **480,000円**
   - 2,400万円超 2,450万円以下: **320,000円**
   - 2,450万円超 2,500万円以下: **160,000円**
   - 2,500万円超: **0円**
3. **課税される所得金額（課税所得）**:
   $$\text{課税所得} = \max(\text{所得金額合計} - \text{所得控除合計}, 0)$$
   ※ 国税通則法に基づき、**千円未満を切捨て**（例: 3,567,890円 → 3,567,000円）。
4. **所得税額の算出（速算表7段階税率ブラケット）**:

| 課税される所得金額 | 税率 | 控除額 |
|---|:---:|:---:|
| 1,000円 〜 1,949,000円 | 5% | 0円 |
| 1,950,000円 〜 3,299,000円 | 10% | 97,500円 |
| 3,300,000円 〜 6,949,000円 | 20% | 427,500円 |
| 6,950,000円 〜 8,999,000円 | 23% | 636,000円 |
| 9,000,000円 〜 17,999,000円 | 33% | 1,536,000円 |
| 18,000,000円 〜 39,999,000円 | 40% | 2,796,000円 |
| 40,000,000円 〜 | 45% | 4,796,000円 |

   ※ 国税通則法に基づき、税額は**百円未満を切捨て**。
5. **復興特別所得税額**:
   $$\text{復興特別所得税} = \lfloor \text{基準所得税額} \times 2.1\% \rfloor \quad (\text{1円未満切捨て})$$
6. **所得税及び復興特別所得税の額（合計）**:
   $$\text{合計税額} = \text{所得税額} + \text{復興特別所得税額}$$

## 7. 帳票PDF出力機能

### 7.1 出力帳票
1. **青色申告決算書（損益計算書）概算PDF**:
   - タイトル、対象年度、納税者情報（氏名、屋号、住所）
   - 売上・仕入・売上総利益
   - 経費各科目の内訳および経費合計
   - 特別控除前所得、青色特別控除額（区分明記）、事業所得金額
2. **確定申告書B 概算PDF**:
   - タイトル、対象年度、納税者情報
   - 事業所得、所得金額合計、基礎控除額、所得控除合計
   - 課税所得金額、所得税額、復興特別所得税額、合計税額

### 7.2 PDF生成エンジンとフォント解決
- **単一バイナリ出力**: Rust クレート `printpdf` を使用し、外部CライブラリやランタイムなしでPDFを構築。
- **日本語フォントの自動探索**:
  1. 環境変数 `TAX_RETURN_FONT` の指定パス。
  2. プロジェクト同梱パス（`assets/fonts/NotoSansJP-Regular.otf` 等）。
  3. 各OSの標準インストールフォント（IPAフォント、IPAexフォント、ヒラギノ角ゴシック、MS Gothic、Meiryo等）。
  4. フォントが見つからない場合のASCIIフォールバック処理。
- **外部定義可能な座標システム**:
  - `templates/blue_return_fields.json` および `templates/form_b_fields.json` をロード。
  - ミリメートル（mm）単位の座標系により、レイアウト調整をバイナリ再コンパイルなしで即時反映可能。
- **保存先ディレクトリとワンクリック起動**:
  - 出力先: `{OS標準データフォルダ}/TaxReturnApplication/exports/{年度}_*.pdf`
  - 「保存先フォルダを開く」ボタンにより、Windows Explorer / macOS Finder / Linux ファイルマネージャーを直接起動可能。

## 8. 決算・設定機能（ClosingPage）

### 8.1 勘定科目・補助科目設定
- **カスタム科目の追加・削除**:
  - ユーザーが任意の科目名（例: 広告宣伝費、クラウド利用料、外注工賃等）および性質（資産・負債・純資産・収益・費用）を指定して自由に追加可能。
  - 仕訳で使用されているカスタム科目は誤削除防止バリデーションにより保護。標準科目は削除不可。
- **補助科目の登録・管理**:
  - 各勘定科目に対して、銀行名（三井住友銀行、みずほ銀行等）、取引先名、クレジットカード名などの補助科目を自由に追加・削除。
  - 仕訳入力時のドロップダウン候補として即時反映。

### 8.2 家事按分機能（Home-Office Expense Allocation）
- **事業割合（%）の設定**:
  - 自宅兼事務所の地代家賃、電気代、インターネット代、スマホ代など、プライベートと事業が混在する経費科目ごとに事業利用割合（0〜100%）を登録。
  - 特定の補助科目に限定した按分ルールの設定も可能。
- **リアルタイム試算プレビュー**:
  - 年間発生総額、事業割合、算定された事業経費額、および個人負担振替額を即時計算して一覧表示。
- **ワンクリック仕訳反映**:
  - 「家事按分仕訳を一括生成・反映」をクリックすると、12月31日付で `借方: 事業主貸 / 貸方: 各経費科目`（摘要: `家事按分振替（...）`）の仕訳を自動生成。
  - 取引を追加・修正した後に再実行した場合も、二重計上されることなく既存の按分仕訳を安全に更新。

### 8.3 年度繰越処理（Fiscal Year Rollover）
- **貸借対照表（B/S）の期首残高引き継ぎ**:
  - 前年末の資産科目残高（現金、普通預金、売掛金等）および負債科目残高（買掛金等）を翌年の期首残高として引き継ぎ。
- **期首元入金（Capital）の自動清算計算**:
  $$\text{翌期首元入金} = \text{前期末元入金} + \text{前期当期純所得} + \text{前期事業主借} - \text{前期事業主貸}$$
  青色申告決算書の標準ルールに基づき、事業主貸・事業主借・所得金額をすべて元入金に清算し、翌期首の事業主貸・事業主借はゼロリセット。
- **開始仕訳の自動生成**:
  - 翌年1月1日付で、各資産・負債の期首残高仕訳（`借方: 資産 / 貸方: 元入金`、`借方: 元入金 / 貸方: 負債`）を自動計上。
- **マスタデータの完全継承**:
  - カスタム科目、補助科目リスト、家事按分ルール、納税者情報、青色特別控除区分を翌年度ファイルへ自動引き継ぎ。
