# Tax Return Application Technical Documentation (English)

This directory contains the technical documentation, specifications, architecture design, and commercial expansion roadmap for the Rust / Dioxus tax return desktop application (`TaxReturnApplication-Dioxus`).

---

## 📚 Document Index

| Document | Title | Description |
|---|---|---|
| [**specifications.md**](./specifications.md) | **Current Feature Specifications** | Complete specifications of all currently implemented features in v0.1.0: Journal entry lifecycle, reactive filters & sorting, legacy Excel 2-row CSV import engine, Blue Return P&L aggregation, Form B income tax estimate calculation, PDF export, and atomic persistence. |
| [**architecture.md**](./architecture.md) | **Architecture Design** | System layered structure, modular isolation, Rust data models (`JournalEntry`, `AccountCode`, `LedgerDocument`, `TaxReportBundle`, etc.), Dioxus reactive signal state, and the 30-case automated test suite. |
| [**roadmap_and_commercial_gap.md**](./roadmap_and_commercial_gap.md) | **Commercial Gap Analysis & Roadmap** | In-depth comparison against commercial tax suites (freee, Money Forward, Yayoi Blue Return, NTA e-Tax portal), inherent advantages, functional gap analysis, and a 5-phase engineering roadmap to rival and surpass commercial software. |
